Comment Extractor

Paste YouTube videos, playlists or channels. Every public comment comes back as a table you can save as CSV, JSON or Excel. Runs in your browser with your own free API key.

What to extract

    0 means all. Counts top-level comments.

    0 means all. Newest come first for channels.

    How to get a free API key (about 5 minutes)
    1. Open Google Cloud Console and create a project.
    2. Go to APIs & Services → Library, search for “YouTube Data API v3” and enable it.
    3. Go to Credentials → Create credentials → API key, and copy it.
    4. Optional: edit the key and restrict it to YouTube Data API v3 only.

    The free quota is 10,000 units a day. One unit returns up to 100 comments, so that is roughly a million comments a day. The quota resets at midnight Pacific time.
